# パーツ箱ジェネレーター

外寸か内寸と板厚を入れるだけで、留め組みのパーツ箱の3Dモデルと手加工用の図面（A4横・1枚の総合図）ができるWebアプリ。

3D表示に使っている Three.js も MIT ライセンス（CDNから読み込み）。

## 動かし方
ビルド不要の静的サイト。ローカルで見るときはこのフォルダでサーバーを立てる（file:// では動かない）。

```
python -m http.server 5178
```

→ http://localhost:5178

公開は、このフォルダをそのまま Vercel / GitHub Pages / Netlify に置けばよい。

ブラウザが古いJSを使い続けないよう、index.html と src の import に `?v=…` を付けている。ファイルを直したらこの番号を全部まとめて変える。画面左下のバージョン表示は main.js の APP_VERSION / APP_DATE。

## 構成
- `src/geometry.js` 形状計算（各板を半空間の交わりとして作り、溝を取り除く）。各部材の仕上がり寸法（cutList）もここ。
- `src/kidori.js` 木取り：板の幅と残しろ（初期 3mm、長さ・幅に足す）から、必要な板の長さと並べ方を出す。木目は部材の長さ方向。側板・背板・前板の4枚の分け方を全部（15通り）試して一番短いものを選ぶ。底板は厚さが違うので別の板（図も1枚）。図には部材の外形（側板は五角形）を太線、切り出す大きさを破線で描く。端の捨て代はなし
- `src/drawing.js` 図面SVG（隠れ線処理、断面、寸法線）。1枚目は総合図（平面図＋右側面図＋寸法一覧＋木取り。上に平面図、下に右側面図。幅の広い箱は2つの図を左右に並べる。右の列に注記、左の空いた角に立体図）。組立図・部材図（側板・背板・前板・底板）は総合図に含まれるので2026-11-22に外した
- `src/view3d.js` Three.js の3D表示（寸法表示・分解・2段積み）
- `src/solid.js` 3Dプリント用：箱を一塊のすき間のない立体（外形の凸から内側の空間の凸を引く）にしてバイナリSTL（mm）で書き出す。溝の穴は埋まる。「底の下を埋める」（初期オン）で底板の下のすき間も埋め、支えなしで刷れる。全辺がちょうど2枚の三角形で共有されることを確認済み
- `src/main.js` 入力欄（外寸／内寸）、URL共有（#W=140&L=210&H=140&t=12、内寸モードは &m=in、板の幅 &bw=、残しろ &ka=）、印刷。「木取り」タブ（以前の部材表の代わり）
- `tests/sweep.js` 寸法をいろいろ変えて形と図面が破綻しないか調べる開発用テスト（下記）

## 入力
- 外寸と内寸を並べて表示し、どちらを打っても反対側が連動して変わる
- 外寸：幅 W・奥行 L（先端まで）・高さ H
- 内寸：内幅 = W − 2t、内奥行（底面）= D − t√2、深さ = H − t（底板の上面から縁まで）
- 「板厚を変えたとき 外寸を保つ／内寸を保つ」で、板厚を変えたときに動かさない側を選ぶ（URLでは内寸を保つとき &m=in）
- 「⇄ 縦横を入れ替え」：内寸の幅と奥行を入れ替える（前板が斜めなので外寸はそのままは入れ替わらない）
- テンプレート（A5・B5・A4・B4・A3。長い辺が左右で入り、縦長は入れ替えボタンで）：コピー用紙500枚（約50mm）が入る箱。内寸 = 紙 + ゆとり（両側の合計。初期 3mm＝片側1.5mm、テンプレート選択中に欄で変えられる）、深さ 65mm、板厚は A5〜A4 が 12mm・B4/A3 が 15mm。押すと「内寸を保つ」になる。10通りすべて破綻チェック済み
- 前板の上端の高さ zf = H/2 + t/√2。内奥行はここで最大 = 全奥行 − t(1 + 1/√2)
- 容量 = 内幅 ×〔(zf − t)(D − t − t√2) + (zf² − t²)/2 + (H − zf)(D − t + H) − (H² − zf²)/2〕
  （前は前板の内面 y+z=t√2、その上は側板の前の縁 y=z−H で囲む。側板の前の縁は前板の内側の上端を通る。上端の小さな面取りは無視。モンテカルロと0.1%以内で一致）
- 3D画面の「寸法」で外寸／内寸の寸法線を重ねて表示（分解・2段積みのときは出さない）

## 破綻チェック
サーバーを立てた状態でブラウザのコンソールから:

```
const m = await import('/tests/sweep.js'); const r = await m.run({ n: 600 }); r.filter(x => x.issues?.length)
```

各寸法について、部材どうしの干渉・すき間・余分な材（期待形状とのモンテカルロ比較）、体積、NaN、図面の紙からのはみ出し・文字の重なり・主図が詳細列や表題欄に入り込んでいないかを調べる。
2026-11-21 時点で 600 通り（うち警告で止まる 79 通り）すべて問題なし（総合図を足したあとも同じ）。

## 形の決まり
- 外幅 W、高さ H、後ろの奥行 D、全奥行 = D + H/2（内部では基準寸法 d と倍率 dx・dy・dz で持つ）
- 溝・底板厚 g = t/3（下端から t−g 〜 t）、面取り c = 2t/3（底の外側・上の内側）
- 四隅は45°留め。前板は45°に傾き、下端は水平、上端は直角
- 積み重ねると面取りどうしが噛み合い、1段 = H + t − 2c
- 溝は端から端まで通すので、前の留めの下に溝幅ぶんの小さな穴が見える（設計どおり）

元の設計データと3通りの寸法で照合済み（各板の体積・外寸が 0.01mm³ 以内で一致）。
